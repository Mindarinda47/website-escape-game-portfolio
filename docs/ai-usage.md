# AI 활용 범위

이 프로젝트는 AI 활용 게임 제작을 주제로 한 1인 참가 프로젝트입니다.

## 직접 수행한 부분

- 게임 콘셉트와 퍼즐 연결 방식 결정
- 기능 요구사항과 제약조건 정의
- AI 제안 코드의 채택 여부 판단
- 실행 오류와 게임 로직 오류 확인
- 상태 구조 수정과 테스트 작성
- 최종 기능 통합

## AI가 보조한 부분

- 구현 초안과 대안 제안
- 반복 코드 작성 보조
- 디버깅 후보 원인 제안
- 일부 문서와 에셋 제작 보조

AI 출력은 그대로 완료물로 간주하지 않고 실제 실행, 타입 검사, 자동화 테스트를 통해 검증했습니다.
