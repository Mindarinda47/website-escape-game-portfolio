# 문제해결 사례

## 벽을 무시하는 공격과 탐지

적 탐지와 공격 판정에 단순 거리만 사용하면 벽 뒤의 플레이어까지 영향을 받았습니다. 충돌 정보와 공간 조건을 함께 검사하도록 수정하고 벽 차단 동작을 테스트로 고정했습니다.

## 위험 지역 생성

플레이어가 적 또는 충돌 지형과 가까운 위치에 생성될 수 있었습니다. 후보 위치를 평가하고 안전 조건을 만족하는 위치를 선택하는 방식으로 변경했습니다.

## 저장 데이터 손상

로컬 저장 데이터가 누락되거나 이전 버전 형식이면 실행 상태가 깨질 수 있었습니다. 버전 확인, 기본값 병합, 손상 데이터 복구 경로를 추가하고 관련 테스트를 작성했습니다.

## 남은 한계

- 브라우저 UI와 Canvas 미니게임의 결합도가 일부 남아 있습니다.
- 전체 플레이 시간을 기준으로 한 난이도 검증 자료는 부족합니다.
